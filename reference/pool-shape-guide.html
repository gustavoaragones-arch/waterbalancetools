Pool Shape & Volume Calculation Guide

v2026.07

The correct volume calculation depends on pool shape. This guide shows the formula and method for each common pool shape.

Overview

Every pool shape has a volume formula. For irregular shapes, divide the pool into sections, calculate each section, and add them together.

Volume Formula by Pool Shape

ShapeFormulaNotes
RectangularL × W × D × 7.48D = average depth in feet
Circularπ × r² × D × 7.48r = radius (diameter / 2)
OvalL × W × D × 7.48 × 0.890.89 is oval correction factor
L-shapedDivide into two rectangles, calculate each, addSplit at the inside corner
KidneyApproximate as average length × average width × D × 7.48 × 0.850.85 is kidney approximation factor
Free-formDivide into approximate rectangles, calculate each, addMore sections = more accuracy
Pool with beach entryCalculate main pool + beach section separatelyBeach section has variable depth

Notes

  • A 10% volume error results in 10% error in every chemical dose.
  • Use the pool volume calculator for guided step-by-step volume calculation.
  • If uncertain about pool shape, divide into more sections for greater accuracy.
