# Phase 7V -- Production Changes

Every change made at the smallest authoritative source; full derivation in `PH-IMPLEMENTATION.md`, full evidence trail in `DECISION-MATRIX.csv`.

## 1. `js/calc-utils.js`

**OLD:** `calculatePHAdjustment` returned `{ ounces, direction, diff }`; `ounces = (gal/10000) * |diff| * (6 or 5)`.
**NEW:** Returns `{ valid, direction: 'balanced'|'raise'|'lower', magnitude: null|'small'|'moderate'|'substantial', diff }`. No numeric dose field.
**REASON:** Phase 7U Option A, authorized for implementation this phase.
**RISK:** Low -- output is qualitative text, not a chemical quantity; verified deterministic via direct function calls.

## 2. `js/calculator.js`

**OLD:** `phIncreaserOunces(gallons, phDifference)` and `phReducerOunces(gallons, phDifference)`, both returning ounces.
**NEW:** Single `evaluatePHGuidance(gallons, phDifference)` returning `{ direction, magnitude, diff }`.
**REASON:** Same as above; consolidated into one function since the old direction-specific split no longer serves a purpose once neither branch computes a number.
**RISK:** Low. Export list updated; `chemical-calculator.html` (the only caller) updated in the same pass.

## 3. `calculators/pool-ph-calculator.html`

**OLD:** Submit handler rendered `'Add ' + r.ounces.toFixed(1) + ' oz pH ' + r.direction + '. Re-test after 30 minutes.'`. Meta description/og/twitter/JSON-LD/hero all claimed "exact...ounces". One FAQ item implied a "measured amount". Trust panel note and chemistry-sources block referenced "the dosing formula".
**NEW:** Submit handler renders direction, magnitude (small/moderate/substantial), generic product-label + incremental + retest (30-60 min) guidance. All SEO/hero copy rewritten to remove exactness claims. FAQ item reworded. Trust panel and chemistry-sources copy rewritten to describe the qualitative architecture.
**RISK:** Low -- no form input changed; only script output and prose.

## 4. `calculators/hot-tub-ph-calculator.html`

Same as #3, with the existing "Run jets 20 minutes" hot-tub-specific instruction preserved.

## 5. `calculators/chemical-calculator.html`

**OLD:** pH portion of the shared submit handler called `phIncreaserOunces`/`phReducerOunces` and appended `'X.X oz pH increaser/reducer'` to the combined output. Meta/title/hero claimed "exact chlorine, pH, and alkalinity doses".
**NEW:** pH portion computes a signed diff relative to whichever target bound was crossed, calls `evaluatePHGuidance`, and appends a qualitative guidance line. Chlorine computation and all chlorine-related UI/logic untouched. Meta/title/hero corrected to "chlorine dose and pH adjustment guidance" (the pre-existing, separately-false "alkalinity doses" claim was also removed from this one shared sentence, since the calculator has never computed an alkalinity dose per its own existing trust-panel disclosure -- a minimal, directly-entangled correction).
**RISK:** Low-moderate (shared file with an unrelated chlorine calculation) -- mitigated by touching only the pH-specific code block, verified via `node -c` syntax check on the extracted script and manual trace confirming the chlorine variables/lines are untouched.

## 6. `calculators/index.html` (hub page) and `data/navigation.json`

**OLD:** Card descriptions for the 3 pH-adjacent calculators repeated the same exact-ounces/exact-doses claims.
**NEW:** Regenerated (via `scripts/generate-hubs.js`, reading `data/navigation.json`, itself regenerated by `scripts/generate-navigation.js` from each page's now-corrected meta description) to reflect the new copy. Required two full `npm run build` passes due to a pre-existing generator-ordering quirk (see `BASELINE.md`).
**RISK:** None -- fully generator-derived from already-corrected sources.

## 7. `scripts/data/formulas-data.js` (`formula-04`)

**OLD:** `equation: 'Acid dose (fl oz) = ΔpH × Volume (gal) × (0.0833 ÷ Acid Concentration %)'` (never implemented by any calculator); `variables` described formula terms; `workedExample` abandoned its own calculation mid-formula before switching to an uncited rule of thumb; `references` cited only Taylor Technologies generically.
**NEW:** `equation` states plainly that no validated equation is published and why; `variables` repurposed to list the relevant factors (ΔpH, volume, TA, CYA, product concentration) with explicit notes that none but ΔpH/volume are collected; `workedExample` walks through the calculator's actual qualitative output for a 15,000-gal/7.8→7.4 scenario; `limitations` extended to note the still-open acid-demand-test lead; `references` extended with the Phase 7U-fetched PHTA/Taylor/LaMotte sources already registered in `chemistry-sources.js`.
**REASON:** Section 9's explicit requirement; no new formula was created.
**RISK:** None -- documentation-only, no calculator reads this record's `equation`/`workedExample` fields for computation.

## 8. `scripts/data/trust-calculator-metadata.js`

**OLD:** `pool-ph-calculator`/`hot-tub-ph-calculator` listed `dosage-matrices` (never read) and `muriatic-acid`/`soda-ash` entities (never named by the tool); notes disclosed only "±0.5 pH units" imprecision, not the missing-TA architectural gap. `chemical-calculator`'s notes said "Computes a chlorine dose and a pH dose" (now false for the pH half).
**NEW:** Dependencies narrowed to what the calculators actually use (`chemical-ranges`, `ph`); notes rewritten to accurately state the qualitative architecture, why (TA/CYA/product not collected), and the incremental/retest guidance. `chemical-calculator`'s notes corrected to distinguish the still-numeric chlorine dose from the now-qualitative pH guidance.
**RISK:** None -- metadata only, propagated via `node scripts/generate-trust.js` and the established strip-and-reinject procedure.
